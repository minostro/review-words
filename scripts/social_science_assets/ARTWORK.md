# Original worksheet pictures

These 31 JPEG crops come from the nine worksheet photographs supplied by the user
on 31 October 2026. The user requested using the same worksheet pictures. No new
artwork was generated. Originals are not modified and are not included wholesale.

Reproduce with Pillow installed:

    python -m scripts.extract_social_science_images --source-dir /path/to/photos

The extraction manifest records original photo names, rotation and exact bounds.
Crops omit adjacent printed/handwritten answers. The mayor crop excludes the
label on the lectern. The family crop is an unlabelled group used only as context
for relationship questions, not an identification task about pictured people.

Source pages used for media: school places (p4), school workers (p9), family (p14),
public services (p21), settlements (p24). The other four supplied pages inform
questions and explanations: school matching (p5), family relationships (p15),
neighbourhood organisation (p20), helper dialogues (p23).

The images belong to the original worksheet rights holders and were supplied for
Salvador's personal study deck. These are source assets, not a licence for general
redistribution of the worksheet artwork.
